# 💄 Victoire Beauté - E-commerce Beauty Store

Một ứng dụng e-commerce hiện đại cho cửa hàng mỹ phẩm cao cấp, được xây dựng với React, Tailwind CSS và kiến trúc component-based.

## ✨ Tính Năng

- 🏠 **Homepage**: Hero section, danh mục thịnh hành, sản phẩm bán chạy
- 🛍️ **Products Page**: Danh sách sản phẩm với filters và sorting
- 🛒 **Shopping Cart**: Quản lý giỏ hàng với localStorage persistence
- 📱 **Responsive Design**: Tối ưu cho mobile, tablet và desktop
- 🎨 **Modern UI**: Glass morphism, smooth animations, Material Design colors
- ⚡ **Fast Performance**: Vite build tool, optimized components

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ 
- npm hoặc yarn

### Installation

```bash
# Clone repository
git clone <repository-url>
cd "Victoire Beauté"

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

Mở trình duyệt và truy cập: `http://localhost:5173`

## 🏗️ Kiến Trúc

Dự án sử dụng kiến trúc **Component-Based** với các nguyên tắc:

- **Separation of Concerns**: Tách biệt UI, logic và data
- **Reusability**: Components có thể tái sử dụng
- **Scalability**: Dễ dàng mở rộng và maintain
- **Feature-Based Structure**: Tổ chức theo tính năng
